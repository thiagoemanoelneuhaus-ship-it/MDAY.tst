# Pauta — quadro de trabalho educacional

Protótipo independente para estudar padrões de organização visual de trabalho: quadros, grupos, tarefas, responsáveis, prazos, busca e visualização em tabela ou kanban. Usa dados fictícios, guarda as alterações apenas no `localStorage` do navegador e não se conecta ao Monday.com.

Os componentes de interface vêm do [Vibe Design System](https://github.com/mondaycom/vibe), pacote oficial publicado pela monday.com sob licença MIT. O protótipo não contém marca, código nem dados privados do produto Monday.com.

## Executar

```sh
pnpm install
pnpm dev
```

Para gerar a versão estática:

```sh
pnpm build
```
